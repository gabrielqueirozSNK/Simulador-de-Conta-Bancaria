# Simulador de Conta Bancária

Um projeto simples desenvolvido em Java para simular operações básicas de uma conta bancária. Este repositório foi criado para praticar conceitos iniciais de Programação Orientada a Objetos (POO), como criação de classes, métodos e instâncias.

# Funcionalidades

-Criação de Conta: Definição do nome do cliente, número da conta e saldo inicial.
-Depósito (depositar): Adiciona um valor especificado ao saldo da conta.
-Saque (sacar): Deduz um valor do saldo atual, incluindo validação para impedir saques caso o saldo seja insuficiente.
-Consulta de Dados (informacoes): Exibe no console os dados atuais da conta (cliente, número e saldo).

# Estrutura do Projeto

O projeto é composto por duas classes principais:
-conta.java: Classe que define o modelo da conta bancária, contendo os atributos e as regras de negócio (métodos de saque e depósito).
-App.java: Classe principal que contém o método main para instanciar as contas e testar as operações no terminal.
